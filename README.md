## 🚀 Features

- **Boot Animation** — Neon β logo with terminal diagnostics
- **Onboarding** — First-time user profile setup
- **Server-side Storage** — Movies saved in `uploads/` folder via Node.js
- **Auto-Resume** — Remembers exact timestamp across browser refreshes
- **Genre Playlists** — Create named playlists (Romance, Action, etc.)
- **Subtitle Studio** — 30+ fonts, 40+ colors, SRT/VTT/ASS support
- **3D / 4D / 5D Orbit** — Mouse-drag perspective transforms
- **Audio Lab** — Volume boost to 1000%, headphone mode
- **Clip Downloader** — Set A-B points and download scene as .webm
- **Screen Shapes** — 40+ shapes (Circle, Hexagon, Star, Diamond, etc.)
- **Themes** — 40+ built-in color themes + custom accent/frame color
- **Keyboard Shortcuts** — 25+ shortcuts
- **Right-Click Menu** — Custom context menu on video
- **Scroll Volume** — Mouse wheel on video = volume control
- **Toggles Bar** — Quick-access toggles for Loop, Subs, Mute, Speed, Mode
- **PiP Mode** — Picture-in-Picture floating window
- **A-B Loop** — Repeat any scene section
- **Snapshot** — Save video frame as PNG
- **Backup/Restore** — Export/import playlist as JSON
