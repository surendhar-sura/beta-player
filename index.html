A passionate frontend developer and UI/UX enthusiast pursuing B.E. CSE at Bannari Amman Institute of Technology, one of the premier engineering institutions in Tamil Nadu.

BETA PLAYER is my flagship personal project — a fully-featured, immersive local video player built entirely with vanilla HTML5, CSS3, and JavaScript (ES6+). No external frameworks. No libraries. Pure raw code and creativity.

Through this project, I've deeply explored: IndexedDB & server-side file storage, Web Audio API for real-time audio processing, Canvas API for spectrum visualizer, MediaRecorder API for scene clip download, CSS 3D transforms for orbit/4D/5D effects, Range-based HTTP streaming for large video files, and advanced keyboard event systems.
